# Traffic Prediction & Urban Mobility Analysis

A data analysis and machine learning project focused on understanding urban mobility patterns and predicting traffic-related outcomes using Python and Streamlit.

## Project Overview

This project analyzes Uber and Lyft cab ride data to identify mobility patterns, understand demand behavior, and build predictive models for transportation-related insights.

## Key Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Spatial and Temporal Analysis
- K-Means Clustering
- Machine Learning Prediction
- Interactive Streamlit Application

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Streamlit

## Project Workflow

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Spatio-Temporal Analysis
5. Clustering and Pattern Analysis
6. Machine Learning Modeling
7. Interactive Visualization and Prediction
